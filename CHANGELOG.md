# Super IDE - Changelog

## [1.0.0] - 2026-09-04

### Added
- ✨ Code Editor with syntax highlighting
- ✨ Game Engine 2D with canvas support
- ✨ File Manager with drag & drop
- ✨ Web Scraper for data extraction
- ✨ Dark/Light theme support
- ✨ Console with command execution
- ✨ Multi-file support with tabs
- ✨ Auto-save functionality
- ✨ Settings panel
- ✨ Real-time preview
- ✨ Express.js backend
- ✨ API endpoints for all features
- ✨ Security with helmet & CORS
- ✨ Rate limiting

### Features
- Code editor supporting HTML, CSS, JavaScript, JSON, XML
- Game engine with collision detection
- File upload and management
- Web scraping with CSS selectors
- User authentication ready
- Database integration (MongoDB)

### Technologies
- Frontend: HTML5, CSS3, JavaScript (Vanilla)
- Backend: Node.js, Express.js
- Database: MongoDB (optional)
- Security: bcrypt, JWT, Helmet
- Utilities: Axios, Cheerio, Multer, Socket.io
